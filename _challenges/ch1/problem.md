# Challenge 1 — Grid Walker

This is deliberately very easy.

Create a **10 × 10 grid** on the Canvas.

There is one player occupying exactly **one cell**.

### Behavior

- Start the player somewhere in the grid.
- `↑` → move one cell up.
- `↓` → move one cell down.
- `←` → move one cell left.
- `→` → move one cell right.
- The player **cannot leave the grid**.
- Draw the grid and the player.

That's the entire problem.

### Your objective

Don't worry about architecture or making this a "game."

I'm interested in whether you naturally figure out:

- how to represent the player's grid position
- how to translate a grid position into a visual position
- how to handle movement
- how to enforce the boundaries

### Prerequisite toolbox

You already know everything required, but explicitly:

**Programming**

- Variables/state
- `if` conditions
- Keyboard input
- Functions/classes if you want them

**Math**

- Addition
- Subtraction
- Comparison
- Basic multiplication

**Grid concepts**

- Row/column or `x/y` coordinates
- Fixed cell size
- Grid boundaries

**Algorithms/data structures**

- None.
